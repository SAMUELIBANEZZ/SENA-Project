## 🚀 Sobre el Portafolio y la Iniciativa

Este repositorio contiene el desarrollo conceptual, la documentación de investigación y la interfaz web interactiva para el proyecto de **Implementación de Redes y Servicios de Telecomunicaciones**.

La iniciativa aborda la creciente exposición a amenazas digitales en la región de Cúcuta, planteando soluciones desde el diseño seguro de redes (segmentación con VLANs, IPv4/IPv6) hasta la concientización preventiva frente a ciberataques impulsados por inteligencia artificial.

---

## 🛠️ Tecnologías y Estándares Implementados

* **Desarrollo Web & UI:** HTML5, CSS3, JavaScript avanzado, Tailwind CSS (estética de alta visibilidad).
* **Infraestructura & Redes:** Modelado de topologías seguras, control de tráfico, direccionamiento robusto.
* **Marcos de Seguridad:** Enfoque *Zero-Trust* (NIST SP 800-207) y estándares criptográficos (TLS 1.3 / IPsec).
* **Visualización de Datos:** Integración con Chart.js para telemetría y análisis de incidentes simulados.
